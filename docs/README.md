# Dokumenty prawne

Pliki w tym katalogu to **szkielety** dokumentów wymaganych przy wdrożeniu.
**Wymagają konsultacji z prawnikiem specjalizującym się w RODO medycznym**
(idealnie z doświadczeniem w art. 9 RODO — dane o stanie zdrowia) przed
udostępnieniem aplikacji realnym pacjentom.

- [`DPIA_szablon.md`](./DPIA_szablon.md) — ocena skutków dla ochrony danych
  (art. 35 RODO). Obowiązkowa przy przetwarzaniu danych wrażliwych na dużą skalę.
- [`regulamin.md`](./regulamin.md) — regulamin korzystania z aplikacji przez
  lekarza.
- [`polityka_prywatnosci.md`](./polityka_prywatnosci.md) — polityka prywatności
  pokazywana pacjentowi przed uzyskaniem zgody na nagrywanie.
